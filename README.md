# Earthan Luo's Blog

[![Jekyll](https://img.shields.io/badge/theme-Chirpy-blue.svg)](https://github.com/cotes2020/jekyll-theme-chirpy)
[![GitHub Pages](https://img.shields.io/badge/hosted%20on-GitHub%20Pages-brightgreen)](https://pages.github.com/)

个人技术博客，基于 [Jekyll](https://jekyllrb.com/) 与 [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 主题构建，托管于 GitHub Pages。

## 内容

博客主要涵盖以下方向：

- **数学基础** — 线性代数、概率论、随机过程
- **最优化方法** — 线性规划、无约束优化、约束优化、二次规划
- **矩阵理论** — 矩阵分解、若当标准形、内积空间与等距变换
- **AI 辅助** — 如何利用 AI 进行文献快速阅读

## 本地开发

```bash
# 安装依赖
bundle install

# 启动本地服务
bundle exec jekyll s
```

访问 `http://localhost:4000` 即可预览。

## 构建与部署

推送到 `main` 分支后，GitHub Actions 会自动构建并部署到 GitHub Pages。
